# Character Images Directory

This directory contains character portrait images for the FOQUES Quest System project.

## Required Images

Place the following character images in this directory:

### Quest 1 Characters:
- **raaz.jpg** - Red lynx character portrait
- **kenji.jpg** - Human survivor character portrait

### Quest 2 Characters:
- **tala.jpg** - Black raven character portrait
- **arlen.jpg** - Beaver character portrait

## Image Specifications

**Recommended dimensions:** 800x600px (aspect ratio 4:3)
**Format:** JPG, PNG, or WebP
**File size:** Keep under 500KB for optimal loading

## Naming Convention

Use lowercase filenames matching the character names:
- raaz.jpg
- kenji.jpg
- tala.jpg
- arlen.jpg

## Fallback Behavior

If an image fails to load, the system will automatically display a gray placeholder with "Image Placeholder" text.

## Visual Style Recommendations

For consistency with the FOQUES narrative aesthetic:
- Dark, atmospheric tones
- Northern wilderness setting
- Animal characters should show realistic features with subtle hints of their personality
- Human character (Kenji) should appear weathered and worn from survival
- Consider showing environmental context (snow, forest, corruption hints)

## Example Sources

You can find suitable reference images from:
- Wildlife photography
- Concept art repositories (ArtStation, DeviantArt)
- AI-generated art tools (Midjourney, DALL-E, Stable Diffusion)
- Stock photo sites (Unsplash, Pexels for nature/animal photos)

**Important:** Ensure you have rights to use any images you place here for portfolio purposes.
